# RGB 摄像头识别

当前阶段：内置 / USB 彩色摄像头 → PNG 送检帧 → 用户原 det_color / det_rect → 颜色、矩形框、中心和角度。识别结果不控制机械臂或底盘。

新增任务选择：常见物体检测、检测＋前景分割、手动框选前景分割，详见 [物体与分割说明](objects.md)。下文原算法阈值、颜色占比与 0.4 秒等待只适用于颜色模式。真实 D435 已做功能连通测试，未做识别准确率评测，金属保温杯仍有混淆和漏检，见 [实测记录](speech.md)。

## 启动

安装 requirements.txt 中的 OpenCV / NumPy 后，在项目目录运行 `python -B app.py --vision-only`，或双击 start-camera.cmd。此模式不需要 Node.js。默认端口 8767；占用时加 `--port 8769` 并访问对应端口。

用本机 Edge / Chrome 打开 `http://127.0.0.1:8767/vision.html?source=camera`。点击“刷新设备列表”，选择摄像头并点击“打开摄像头”。首次需要允许浏览器访问相机；授权前设备名称可能为空或显示“摄像头 1”。打开后刷新列表可显示更完整名称。

## 目前这台电脑的设备

2026-10-18 的只读设备枚举显示：

- USB2.0 HD UVC WebCam：内置普通摄像头。
- Intel(R) RealSense(TM) Depth Camera 435 with RGB Module RGB：新接 D435 的彩色接口。
- Intel(R) RealSense(TM) Depth Camera 435 with RGB Module Depth：同一 D435 的深度接口。

D435 同时具有 RGB 与深度功能，型号可参考 [官方产品说明](https://www.realsenseai.com/products/stereo-depth-camera-d435/)。已在本机网页实测打开 D435 RGB，采集到 640×480 彩色画面并调用原识别算法；当时送检帧返回“未识别到目标”。这验证了采集与送检链路，尚未完成真实红蓝黄物体的识别验收，也没有验证深度或 RGB-D 配准。摄像头随后已按用户要求关闭。

当前选 RGB 接口做颜色识别，Depth / IR 接口按名称标记并禁选。设备名称只作界面辅助，不能用通用 UVC 名称判定任意设备是否有深度功能。浏览器打开彩色视频不会自动获得毫米深度；不从灰度图或 RGB 画面伪造距离。

## 操作与结果

先把红、蓝或黄色物体放在画面内，选择目标颜色，点击“拍摄一帧并识别”。“连续识别”会在上一次返回后继续采集下一帧，暂停时不排队补帧。原函数有 0.4 秒等待，因此检测不会达到实时预览的帧率。

实时预览与送检帧分开显示，检测框只画在对应送检帧上。输入按比例缩放到 320×240，必要时留边；不拉伸画面。中心、像素偏差和角度均对应这张送检图像，不是原始传感器坐标，更不是机器人世界坐标。中心放大只改变送检区域，实时预览仍显示完整画面。

更换目标、图像来源或裁剪区域时丢弃旧结果；未检测到目标时清空旧中心和角度，避免把上一帧的成功结果当成新结果。

## 识别不到时

1. 确认选了 RGB 接口，能够看到彩色预览。
2. 物体移近，或使用中心放大；原算法要求对应颜色占画面约 4% 以上，还包含轮廓尺寸限制。
3. 使用较均匀光照、少反光表面；原 HSV 配置来自原工位，不保证适合所有相机和光照。当前没有替换原函数或悄悄放宽阈值。
4. 检查所选目标颜色与实际物体一致。红蓝黄按单一目标测试最容易定位问题。
5. 回到合成测试图确认本机服务和原算法可用，再检查真实图像条件。

## 摄像头无法打开时

- 权限被拒绝：在浏览器地址栏允许摄像头，并检查 Windows 相机隐私设置。
- 相机被占用：关闭相机软件、会议软件等，再重新打开。
- 找不到设备：检查线缆、供电与 USB 连接，刷新列表。
- 请求一直未完成：20 秒后会超时并允许重试；可以主动点击关闭取消。迟到的授权视频流也会自动释放。
- 内嵌浏览器不支持：使用本机 Edge / Chrome 打开 localhost 地址。不要通过非本机 HTTP 地址或静态博客调用本机摄像头识别服务。

切换图像来源、重置页面或关闭页面会释放视频轨道。取消勾选连续识别只暂停送检，仍保留实时预览；需要关闭设备请点击“关闭摄像头”。麦克风始终不申请，图像只在浏览器与本机 Python 服务内存中处理。

## D435 真实深度入口

普通浏览器 RGB 模式不提供真实距离。v0.6.0 同步了独立 RealSense RGB-D 入口，使用可选 SDK 采集同帧彩色与深度、完成配准，并在页面显示两张对应图像及点选光轴深度 Z，见 [安装与测量边界](realsense-depth.md)。

仓库只包含适配源码与可选依赖清单，不包含 SDK 二进制。暂停的 Astra Pro SC / OpenNI 原型不包含在本版中；OpenNI 原型不是 D435 的深度驱动。

浏览器采集依据：[getUserMedia](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getUserMedia)、[enumerateDevices](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/enumerateDevices)。
