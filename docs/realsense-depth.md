# D435 真实 RGB-D 图像与测距

2026-10-24 完成实机连通，v0.6.0 同步到 GitHub。以下命令均在仓库根目录运行；D435 既可用作普通 RGB 摄像头，也可通过此入口采集配准 RGB-D。

## 打开与使用

启动 `python -B app.py --vision-only --port 8771`，打开 `http://127.0.0.1:8771/vision.html?source=realsense&task=objects`。也可在页面“图像来源”选择“RealSense RGB-D / 真实测距”，然后点击“打开摄像头”。

- 左侧显示真实彩色送检图，右侧显示配准到彩色视角的深度伪彩图，二者来自同一组 SDK frameset。
- 打开后默认连续采集和识别。测距点默认为图像中心；点击彩色图、深度图或候选目标，可更改测距位置。
- 界面显示光轴深度 Z（米和毫米）、7×7 邻域有效样本数、帧号、帧时间差和深度有效比例。
- 检测候选同时显示框中心深度。选择“物体检测＋前景分割”时，使用有效掩膜质心的深度；没有有效掩膜时退回框中心。
- 可关闭“连续识别”观察冻结图。超过 2.5 秒后距离失效，必须重新采集。空闲约 10 秒后后台自动释放设备；需要时重新打开。
- “关闭摄像头”释放 RGB-D。网页退出时也请求关闭，异常退出由空闲超时兜底。

当前 RGB-D 入口支持物体检测和检测＋前景分割；原颜色与手动框选模式可在其他图像来源中继续使用。为保证坐标对应，RGB-D 模式暂不支持前端中心裁剪；两图使用完全相同的缩放。

## 测量的定义与边界

深度原始数据为 Z16，使用设备实际 `get_depth_scale()` 换算毫米；通过 SDK `align(color)` 将深度投影到彩色视角后，再同步缩放到 320×240。输入采集分辨率均为 640×480、30 fps；网页端采用逐帧请求，显示更新率取决于识别和传输耗时。

距离取所选像素 7×7 邻域的有效深度中值。零值、非有限数及本模块 0.15–10 m 取值范围外数据不使用。有效样本少于 9 个或不足邻域的 30%，返回无效；P90−P10 大于 60 mm 与中值 12% 中的较大者时，返回多表面混合，不输出距离。这是工程启发式过滤，不能保证排除所有背景回波。

显示值是相机光轴方向的 Z，并非欧氏直线距离、物体尺寸、抓取位姿或机械臂坐标。边缘、透明、镜面、金属反光和太近物体可能缺深度或读到背景，必须结合图像核对。伪彩固定范围为 0.2–3 m：近处暖色，远处冷色，范围外颜色饱和；黑色为无效深度，不代表零距离。

点测距请求绑定当前显示的帧号。来源改变、迟到响应、旧会话或超过 2.5 秒的帧都不能提供新的有效测距。后台最多保留 8 张短时深度数组，均在内存中；不自动保存照片、深度文件或录像。

## 本机运行库

当前 Python 原本未安装 RealSense SDK，本次把官方 PyPI `pyrealsense2==2.59.1.11053` 安装到项目 `.runtime/realsense`，约 9.4 MB 的 Windows wheel。该目录被 Git 忽略，没有修改系统 Python、安装完整 Viewer 或更新相机固件，也没有下载新的识别模型。

换机器可在项目目录自行准备可选运行库：

```powershell
python -B -m pip install --no-deps --only-binary=:all: --index-url https://pypi.org/simple --target .runtime/realsense -r requirements-depth.txt
```

普通 RGB、仿真及 TTS 不依赖该运行库。SDK 仅在用户点击打开 RGB-D 时导入和启动设备。若提示占用，先关闭浏览器 RGB 预览及其他相机程序；多台 D435 时当前实现拒绝猜测设备。

## 验证

真实 D435 测试已成功：

- 获取 640×480 RGB 与深度，并完成 depth-to-color 配准。
- 独立模块测试的一帧中，画面中心邻域约 324.5 mm，键盘框中心约 505 mm；另一目标的混合深度被拒绝。
- 页面已实际显示两张对应图像、真实深度读数及目标距离。一帧中心读数约 325 mm，帧时间差约 9 ms。数值随场景变化，这不是用尺具核验的准确率或精度承诺。
- 页面中的金属保温杯表面出现较多无效深度，按无效数据显示，没有用 RGB 或预设值补齐。
- 实际点击键盘候选后，测距点为 (75, 156)，界面读数约 502 mm，49/49 个邻域样本有效；点击深度图中心也已验证，遇到保温杯无效区域时明确显示无有效深度。
- 完整 Python 回归 65 项通过；新增前端会话与坐标测试通过，原视觉、TTS、相机和运动回归保持通过。

自动测试使用假相机/数组，硬件连通验证另行使用真实设备。图像只在内存中处理，没有导出照片、深度图或录像，也没有控制实体机器人。
