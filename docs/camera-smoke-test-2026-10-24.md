# 2026-10-24 D435 RGB 实机连通测试

使用本目录 v0.5.0，执行 `python -B app.py --vision-only --port 8771`，在本机浏览器打开 `http://127.0.0.1:8771/vision.html?source=camera&task=segment`。服务只监听回环地址，不启动仿真或实体机器人控制。

浏览器实际选中 `Intel(R) RealSense(TM) Depth Camera 435 with RGB Module RGB (8086:0b07)`，视频元素收到 640×480 帧，readyState 为 4。设备列表同时显示内置 UVC 相机、D435 Depth 与 OBS Virtual Camera；本次仅打开 D435 RGB。

物体检测与 GrabCut 分割使用 320×240 送检图。当前室内画面中，模型返回 3 个 `tv` 类候选；最后一次冻结结果的分数分别为 61.8%、58.8%、41.5%，后台检测/分割耗时为 300.5 ms。这是候选检测结果，不代表经人工标注确认的真实物体数量或正确率。

连续采集时观察到新帧编号更新，并累计至 3 张证据帧。此后暂停连续送检，对所选 `tv` 候选进行同帧框扰动评估：

- 自适应策略在 3/5 次候选后停止，评估耗时 255.2 ms。
- 最小候选掩膜 IoU 为 0.949，中心最大差为 1.56 px。
- 共同前景面积为 3713 px，候选内部像素为 (227, 99)。

这些数值仅表示该帧、该目标和有限框扰动下的分割一致性，不是分割准确率、抓取点或实际距离。暂停后页面按规则显示观测过期，冻结帧仍可分析，不能当作实时证据。

测试结束时保留本机服务与相机预览，连续送检关闭，页面保留供用户继续摆放物体测试。没有导出相机图片、掩膜或录像，没有读取深度流，没有执行机器人动作。透明/反光物体、小目标、遮挡、真实颜色目标识别率，以及 RGB-D 配准、三维定位仍未在本次验证中验收。

上述状态记录的是 RGB 连通阶段。随后完成了 [中文播报](speech.md) 和 [真实 RGB-D 点选测距](realsense-depth.md) 验证；整轮测试结束后已停止视觉服务并释放相机。
