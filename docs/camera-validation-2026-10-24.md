# 2026-10-24 摄像头实操

验证流程：识别物体 → 提取前景 → 检查连续帧位置 → 评估框选敏感性 → 人工复核、导出记录。使用现有 RGB 摄像头即可，无需真实机械臂、底盘或深度 SDK。

## 启动

1. 在项目根目录双击 `start-observation.cmd`。默认 8767 端口占用时，在终端运行 `python -B app.py --vision-only --port 8771`。
2. 打开 <http://127.0.0.1:8767/vision.html?source=camera&task=segment>，自定义端口时同步修改地址。
3. 选择内置摄像头或外接相机的 RGB 接口，点击“打开摄像头”。内嵌浏览器无法授权时，用本机 Edge / Chrome 打开同一地址。页面不会自动打开相机。
4. 使用素色背景与稳定光照，先摆一个不透明杯子、瓶子、书本或手机。透明、反光、细线和严重遮挡物品留作失败样例。

本机已经安装 NumPy / OpenCV；换电脑才需要 `python -m pip install -r requirements.txt`。`--vision-only` 不需要 Node.js 或 npm，独立运动学示例在浏览器内计算。

## 识别和分割

选择“物体检测＋前景分割”，单次识别。观察类别、框与实际送检帧是否对应；预览与送检帧独立显示。目标太小时调整位置或中心放大；类别筛选从 `all` 开始，分数保留默认值。多个目标时点击列表选择目标，人工检查掩膜是否漏掉目标或混入背景。

不在 COCO 80 类中或检测遗漏时，选择“手动框选前景分割”，冻结一帧，拖框包住目标并留少量背景，再点击分割。此模式不需要模型，但没有自动类别识别。GrabCut 是框提示前景提取，当前不是端到端语义分割网络。

## 连续帧与旧帧

在物体模式开启连续识别，保持目标静止。同来源、同类且位置接近的至少三张新鲜帧，才能显示“连续三帧位置稳定”。帧 ID 和视频时间必须更新，同一冻结帧重复送检不会累计。

- 移动目标：中心大幅变化或窗口累计漂移超过 8 像素时重新收集。
- 移走目标：应显示无目标，旧结果不继续计入。
- 暂停连续识别：最后相机帧超过 2.5 秒，应显示观测已过期；更早证据帧也逐步失效。
- 切换摄像头、来源、缩放、类别或所选目标：重新收集。
- 本地图片、合成图和手动冻结图：只显示冻结帧，不会显示实时稳定。

门槛可调整，属于像素启发式检查，不是完整多目标跟踪器或跟踪准确率。邻近同类物体仍可能混淆，低配置电脑也可能无法及时积累三帧，应记录真实耗时后再调整。

## 分割敏感性评估

选择目标，点击“评估所选目标”。这会暂停连续送检，使用当前同一张图；实时预览继续。系统对原框、扩框、缩框等最多五个提示分别执行 GrabCut，比较掩膜 IoU、面积、中心变化和共同前景内部空间。

1. 正常框选并评估，记录结果与耗时。自适应策略达到规则后可在三次候选停止。
2. 同一冻结帧改为固定策略再评估，通常执行五次，比较结果与耗时。改变设置会清除旧评估。
3. 改用切掉目标的紧框、复杂背景或邻近物体，人工检查失败样例。错误掩膜也被判断一致时同样记录，这是需要研究的情况。
4. 黄色标记只是共同前景内部的候选表面像素，不能直接作为真实抓取点。

软时间预算为 4 秒，单次分割不能强制中断，所以实际时间可能超出；候选不足时明确显示未完成。“分割较一致”只表示同帧对有限框扰动的敏感性较小，不是准确率、概率或多视角证据。相机新鲜度单独显示，旧图仍可分析但不能冒充实时观测。

## 导出与复核

人工选择复核标签后，下载观测报告 JSON。每换帧或目标，标签会重置。报告包含帧 ID、来源、图像尺寸、类别与像素框、时序状态、评估策略/门槛/耗时和人工标签，不含图片、掩膜图像或深度缓冲。

先收集 12 组：两个物体 × 简单/复杂背景 × 正常框/紧框/轻遮挡，再挑两个场景试连续识别。样本只用于查错，不能据此报告泛化准确率。需要核对外观时可手动保存送检图并与帧 ID 对照，程序不自动录制。

## 独立运动学对照

展开页面上的独立运动学示例，比较只检查抓取点与检查预抓取、抓取、抬升关键位姿。默认抬升 0.10 m、假设误差 2 mm、速度界 20 mm/s：

- Y=0.760 m：共同采样余量约 39.5 mm，复查时间估计 1.875 s。
- Y=0.795 m：抓取点余量约 40 mm，共同采样余量约 4.5 mm，复查时间估计 0.125 s。
- Y=0.810 m：关键位姿不可达。

示例与摄像头目标没有空间绑定，仅沿 Y 方向以 0.5 mm 步长扫描，没有连续轨迹或碰撞验证。时间来自假设误差/速度界，不是实测有效期；程序未把像素换成毫米、深度或机械臂指令。
